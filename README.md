## Klinoff execution model

A Klinoff program consists of pigs.

Klinoff is a pig-oriented programming language. Each pig is a function, and pigs can call other pigs. Pigs can also loop and jump to other pigs.

A pig may become confused, but this is expected behaviour.

Klinoff is a compiled language. The Klinoff compiler translates Klinoff source code into a binary format that can be executed by the Klinoff runtime.
